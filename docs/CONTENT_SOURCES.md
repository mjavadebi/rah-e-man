# منابع و اعتبار اطلاعات
- تصویر نقشه عمومی دانشگاه و لوگوی دانشگاه: فایل‌های ارسالی کاربر (موجود در assets به عنوان مرجع و لوگو)
- ویژه‌نامه «تپش ۲۶» ورودی‌ها: فایل ارسالی کاربر؛ نوع خدمات دانشگاهی از آن الهام گرفته شده، اما آدرس خدمات و سامانه‌ها تایید نشده است.
- کاربری کلی چهار فاز، وجود ساختمان ترنج و دوطبقه بودن آن: توضیحات مستقیم کاربر.
- تمامی مختصات SVG، فضاهای ساختمان، شماره اتاق‌ها، نام استادان نمونه، مسیرها و محاسبات شبکه: داده آزمایشی تولیدشده برای نشان دادن رفتار محصول؛ نه داده رسمی دانشگاه.
