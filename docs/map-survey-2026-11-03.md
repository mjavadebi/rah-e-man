# نقشه میدانی — ۱۴۰۵/۰۸/۱۲

این سند بر اساس تصویر شماره‌گذاری‌شده‌ای تهیه شده که دانشجو در گفتگو ارسال کرده است.

## محدوده‌های تشخیص‌داده‌شده
| کد | نام در تصویر |
|---|---|
| ۱ | خوابگاه‌ها |
| ۲ | فاز ۱ |
| ۳ | سلف |
| ۴ | ساختمان مدیر دانشگاه و سایر بخش‌ها (جزئیات نامعلوم) |
| ۵ | فاز ۲ |
| ۶ | فاز ۳ |
| ۷ | کارگاه چاپ و باشگاه ورزشی |
| ۸ | سالن ورزشی |
| ۹ | استخر |

## مسیرها
طبق توضیح دانشجو، مسیرهای سفید نقشه مبنای راه‌های قابل عبور پیاده هستند.

**محدودیت مهم:** گره‌ها، اتصال‌ها، فاصله‌ها و شکل دقیق مسیرها در مدل SVG فعلی «شماتیک» و نیازمند برداشت میدانی‌اند. کوتاه‌ترین مسیر Dijkstra فعلا فقط روی این گراف پیشنهادی محاسبه می‌شود؛ نباید به عنوان مسیر واقعی قطعی یا مسیر مناسب افراد کم‌توان معرفی شود.

## وضعیت سایر داده‌ها
- جای دقیق ساختمان ترنج داخل فاز ۳ هنوز اندازه‌گیری/تایید نشده است.
- نام و شماره کلاس‌ها، پلان طبقات، اساتید و دفاتر فعلا دمو هستند.
- محل دفتر آموزش و کتابخانه هنوز از عکس شماره‌گذاری‌شده قابل اثبات نیست.
- برای انتشار رسمی باید محل ورودی ساختمان‌ها، مسیرهای ممنوع، پله‌ها، ساعات سرویس‌ها و دفترها بازبینی شود.

## معماری
- `data.js`: داده‌های پیشین نمونه.
- `survey-2026.js`: لایه تصحیح‌شده محدوده‌ها، گره‌های مسیر و پرسش‌های متداول؛ بعد از `data.js` بارگیری می‌شود.
- `app.js`: ترسیم SVG تعاملی و جست‌وجو/مسیریابی.
- `phase.html` و `place.html`: صفحات جزئیات.

این مستند را در هر بازدید از دانشگاه به‌روزرسانی کنید.
