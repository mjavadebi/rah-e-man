# راهِ من — Rah-e Man 🐦

راهنمای تعاملی فارسی و راست‌به‌چپ دانشگاه ملی مهارت شریعتی تهران. پروژه بر مبنای HTML، CSS، JavaScript و نقشه SVG داخلی ساخته شده و وابستگی به iframe یا سرویس نقشه خارجی ندارد.

## اجرا
`index.html` را باز کنید. صفحات `phase.html` و `place.html` به نقشه اصلی لینک دارند. دارایی‌ها داخل `assets/` هستند.

## ویژگی‌های MVP
- نقشه SVG قابل هاور، کلیک و انتخاب با کیبورد
- ۹ محدوده اصلی بر اساس نقشه علامت‌گذاری‌شده دانشجو
- جست‌وجوی مقصد، سوالات متداول، صفحات فازها و ساختمان‌ها
- مسیر پیشنهادی با الگوریتم Dijkstra روی یک گراف **شماتیک**
- هویت بصری آبی `#07509B`، صورتی `#E8A9BA`، کرم `#F8EDE4` و سبز `#91B9A2`

## وضعیت صحت اطلاعات
نام و موقعیت تقریبی ۹ محدوده مطابق تصویر شماره‌گذاری‌شده دانشجو به‌روز شده‌اند. ساختمان‌ها، اتاق‌ها، طبقات، اساتید و فاصله مسیرهای فعلی هنوز عمدتا **داده نمونه** هستند و برای استفاده واقعی باید با برداشت میدانی جایگزین شوند. مسیر سفید در نقشه منبع، گذرگاه پیاده است؛ گراف فعلی بازسازی تخمینی همین شبکه است و برای هدایت قطعی مردم هنوز مناسب نیست.

## ساختار داده
- `data.js`: داده پایه نمونه
- `survey-2026.js`: اصلاح موقعیت نواحی و مسیرها بر اساس داده‌های تازه
- `app.js`: نقشه تعاملی، جست‌وجو، مسیر و FAQ
- `details.js`: صفحات جزئیات
